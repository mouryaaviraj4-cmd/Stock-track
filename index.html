📱 Ready for Android & Offline Use

Download & Run on Any Android Phone

This app is built as a Single-File Progressive Web App (PWA). It works on every Android phone, tablet, or warehouse PC without needing the Play Store or a monthly server fee.

How to Install as an App on Android Chrome:
  1. Open your hosted GitHub link (or downloaded file) in Chrome on Android.
  2. Tap the three dots menu (⋮) in the top-right corner of Chrome.
  3. Tap "Add to Home screen" or "Install app".
  4. It now appears on your Android home screen with its own icon and opens full-screen!
🌐 Share via GitHub

How Anyone Can Download or Use It from Your GitHub

Follow these 4 beginner steps to put this app on your GitHub so your team or anyone else can run it on Android or download it:

  1. 1
    Download the App File: Click the "Download Standalone App File (index.html)" button on the left.
  2. 2
    Create a GitHub Repository: Sign in to GitHub, tap New Repository, name it cloth-stock-app, and set it to Public.
  3. 3
    Upload index.html: Tap "Add file → Upload files", select your downloaded index.html file, and tap Commit changes.
  4. 4
    Enable Free Live App Link (GitHub Pages): Go to Settings → Pages, choose branch main, and click Save. You'll get a live link (https://yourname.github.io/cloth-stock-app/) that opens directly on any Android phone!
