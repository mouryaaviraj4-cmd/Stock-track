CLOTH STOCK PWA — FREE DEPLOYMENT

This folder is prepared for GitHub Pages. Upload ALL files in this folder to the ROOT of a GitHub repository. Then open repository Settings > Pages, choose Deploy from a branch, select main and /(root), and Save.

After deployment, open the Pages URL in Chrome on your Android phone. Tap ⋮ > Install app (or Add to Home screen).

IMPORTANT: Inventory is stored in this browser on this device (localStorage). It does NOT automatically sync to other phones. Export CSV regularly as a backup. The current app loads Tailwind CSS and the barcode scanner library from external CDNs, so those features need internet access. This package caches the app shell but is not a fully offline copy.
